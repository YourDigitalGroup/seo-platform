Step 1 — Set the client up. (Once per client, then only when something changes.)
  1. Check the URL, target market and plan, then fill in the Business Facts. Amber fields were read off the client's website — verify them; everything saves as you type.
  2. Add the target keywords and targeted landing pages, then the Local Listing Optimization citation pack and LLO sync.
  3. Add any Client notes the team should know, then click Generate package →. That one button runs the audit, writes the fixes and drafts the content — everything on the other tabs comes from it — and hands the package to the SEO/AEO specialist on Trello automatically (Sarah unless the client has its own strategist).
  4. In Platform Access, connect what you have: the WordPress key (from the client site's connector plugin — see tab ④), Search Console, Business Profile.

Step 2 — Read the plan. (Nothing to implement on this tab — it tells you what the platform found and what it's doing about it.)
  1. The big number is the site's audit score out of 100; the campaign drives it to 90+.
  2. The Directive is the work order. In production = being written for you now (tabs ③ and ④). Scheduled = a later month. Available on… = needs a plan upgrade — mention it to the account manager.
  3. Competitors and the content-gap list are editable — tick any gap keyword worth writing and it joins the Content tab queue.
  4. Deployed the fixes? Click ↻ Re-run audit — it re-measures and rescores the site without rebuilding the package, and Audit History below keeps every run so you can watch the score climb.

Step 3 — Review and approve the writing.
  1. Every queued piece drafts itself after Generate. Click Open on each one, read it, and edit anything you'd say differently.
  2. If a red Auto-fix flagged button appears, click it once — it rewrites any draft that broke a compliance rule (invented claims, placeholders) using the approved business facts.
  3. Click Approve on drafts that are ready. Only approved pieces ship — the deploy file leaves unapproved drafts behind, and approval is what puts a piece on the publishing schedule.
  4. Want more options? Suggest topics proposes ideas from the business description — tick the good ones.

Step 4 — Put it on the website (WordPress).
  1. The fixes below are already written — schema, titles, robots.txt, all of it. Nothing here changes how the site looks.
  2. One-time per site: wp-admin → Plugins → Add New → Upload → seo-platform-connector.zip → Activate. Then Settings → SEO Platform → copy the API key into this client's Platform Access on tab ①.
  3. Deploy everything in one shot: click Deploy file (.json) in the header above, then in wp-admin go to Settings → SEO Platform → Import package, choose the file, click Import & apply. It applies every fix and schedules the approved content, then prints a report — anything listed under Manual follow-ups is yours to do by hand.
  4. Google Business Profile posts can't be automated: copy each post's text from the campaign doc (tab ⑤) into business.google.com → Add update.
  5. Citations (LLO): on tab ① open LLO → Citation pack — work the checklist top to bottom, pasting the NAP block exactly. For bulk, import the Citations CSV into BrightLocal/Whitespark.
